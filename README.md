## What It Does
- Adds an element that renders the **exact background** imported by `local_certificateimport` for each issued certificate.
- Reads the `backgroundfileid` stored in `local_certimp_items` and paints the JPEG on top of the certificate page.
- Falls back to a concise status message when the certificate was not produced via the importer.
- Lets you keep a manual fallback image in the element itself, so certificates issued outside the importer are still rendered.
- Shows the most recently imported image in the designer so positioning matches the final PDF (falls back to the manual image or a placeholder until imports exist).
- Always behaves like a full-page background so the imported asset automatically covers the entire certificate without extra clicks.

This keeps the PDF generated by `tool_certificate` visually identical to the original PDF that was imported for a specific learner.

---

## Installation
1. Copy this directory to `admin/tool/certificate/element/certificat` in your Moodle codebase.  
2. Ensure the plugins `tool_certificate`, `mod_coursecertificate`, and `local_certificateimport` are installed.  
3. Run the Moodle upgrade (`php admin/cli/upgrade.php`).

---

## Using the Element
- Open a Workplace certificate template and add the element **“Imported certificate background”**.  
- Stretch the element so it covers the full page if you want the imported PDF image to become the background.  
- Issue certificates through `local_certificateimport` – the element automatically picks up the stored background for each issue.  
- (Optional) Upload a fallback image that will be used whenever a certificate was not produced via the importer.  
- When designing or previewing a page the element displays the most recently imported image (falls back to a placeholder until the first import happens).

---

## Stored Data & Privacy
- The element does **not** introduce new database tables.  
- It only reads the `backgroundfileid` already stored by `local_certificateimport` in `local_certimp_items`.  
- No personal data is collected or persisted by this plugin.

---

## Compatibility
- Moodle Workplace 4.5+.  
- Requires `tool_certificate` and `local_certificateimport` (schema version `2025111500`).  
- Release: 1.0.0 (`$plugin->version = 2025111500`).

## Development Notes
- Rendering logic lives in `classes/element.php` – it fetches the background file, streams it via `element_helper::render_image()`, and mirrors the layout in the designer.  
- There are no upgrade steps nor database tables; `db/install.xml` stays empty on purpose.  
- Run PHPCS with the Moodle standard before submitting patches.
